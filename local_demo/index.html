Operational checklist

Use these checks when preparing a live field demo.

API key present

Set SARVAM_API_KEY in your environment before launching the web server.

Microphone permissions

Allow browser mic access so the voice workflow can capture and upload audio.

Backend fallback chain

Use auto TTS to prioritize Piper, then espeak-ng, then edge-tts if needed.

Watch metrics per call

Use STT/translate/TTS timings to identify bottlenecks before deployment.
